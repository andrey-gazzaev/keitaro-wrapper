# Создатель кампаний

Создатель собирает в Keitaro новую кампанию по трём полям: название, гео-код страны и id оффера. После обрезки пробелов название принимается только если начинается с `test_gazzaev_`. Кампания сразу пригодна для обёртки: у неё два потока, домен, группа и источник.

## Бизнес-процесс

Пользователь передаёт название кампании, гео-код страны и id оффера, который уже есть в Keitaro. Домен, группу и источник он не выбирает.

1. Создатель заводит кампанию с переданным названием. В Keitaro и в сохранённой строке лежит эта же строка. Создатель не дописывает `test_gazzaev_` сам.
2. Домен, группу кампании и источник он проставляет из сущностей, которые уже отдаёт API Keitaro. В трекере к этому моменту есть хотя бы один домен, одна группа кампаний и один источник.
3. У кампании два потока, по порядку.
   - Первый ловит всех из страны с переданным гео-кодом и отправляет их на Google. Офферов в этом потоке нет.
   - Второй стоит следом и отправляет на оффер с переданным id. Страну забирает первый поток, поэтому второй получает остальных. Оффер в нём один, его вес 100%.

Обёртка над уже созданной кампанией описана в [черновике потоков](wrapper.md). Этот создатель собирает кампанию той же формы: страновый редирект на Google и следующий поток на оффер.

## Тест-кейсы

Каждый кейс лежит в своём файле. На вход везде одно и то же: название, гео-код и id существующего оффера.

### Создание кампании

Создатель заводит кампанию в Keitaro и даёт ей переданное название.

- [CC-01. Кампания создаётся с переданным названием](cases/campaign/create/cc-01.md)

### Поток страны

Первый поток фильтрует страну и уводит её на Google, без офферов.

- [CC-02. Первый поток ловит страну и ведёт на Google](cases/campaign/country/cc-02.md)

### Поток оффера

Второй поток забирает тех, кого не забрал первый, и отправляет их на выбранный оффер.

- [CC-03. Второй поток отправляет на выбранный оффер](cases/campaign/offer/cc-03.md)

### Домен, группа и источник

Эти три настройки есть в API Keitaro. Создатель проставляет на кампанию существующие сущности, а не пустые значения.

- [CC-04. У кампании задан домен из API](cases/campaign/settings/cc-04.md)
- [CC-05. У кампании задана группа из API](cases/campaign/settings/cc-05.md)
- [CC-06. У кампании задан источник из API](cases/campaign/settings/cc-06.md)
