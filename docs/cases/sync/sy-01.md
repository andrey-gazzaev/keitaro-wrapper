# SY-01. Удаление в Keitaro становится removed

Синхронизация с Keitaro. Процесс и фикстура — в [обёртке над Keitaro](../../wrapper.md).

## Шаги

В Keitaro удалить несколько офферов потока, сохранить изменения, затем в обёртке снова нажать Fetch Streams.

## Ожидание

Офферы, которые обёртка уже знала и которых больше нет в Keitaro, остаются в обёртке. Они серые, статус `removed`. Bring back может вернуть такой оффер.
