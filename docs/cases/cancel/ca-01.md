# CA-01. Cancel снимает неопубликованные добавления

Отмена черновика. Процесс и фикстура — в [обёртке над Keitaro](../../wrapper.md).

В субтитрах фраза про Cancel обрывается: «привязка офер останется, привязка удалится». Ожидание собрано из неё и из слов «удалятся из нашей базы»: привязка к потоку удаляется, сам оффер остаётся.

## Шаги

Добавить оффер и, пока поток жёлтый и не опубликован, нажать Cancel.

## Ожидание

Офферы, добавленные до публикации, снимаются с потока. Привязка к потоку удаляется, сам оффер остаётся. Поток из жёлтого становится белым. В Keitaro ничего не менялось.
