# CC-01. Кампания создаётся с переданным названием

Создание кампании. Процесс — в [создателе кампаний](../../../campaign-creator.md).

## Шаги

Вызвать создатель с названием, гео-кодом страны и id оффера, который есть в Keitaro. После обрезки пробелов название начинается с `test_gazzaev_`.

## Ожидание

В Keitaro появляется кампания с переданным названием, и это название начинается с `test_gazzaev_`.
