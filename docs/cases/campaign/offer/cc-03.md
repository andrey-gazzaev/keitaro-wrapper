# CC-03. Второй поток отправляет на выбранный оффер

Поток оффера. Процесс — в [создателе кампаний](../../../campaign-creator.md).

## Шаги

Создать кампанию с гео-кодом страны и id оффера.

## Ожидание

Второй поток стоит после странового. Фильтра по этой стране у него нет. Поток отправляет трафик на оффер с переданным id, вес оффера 100%.
