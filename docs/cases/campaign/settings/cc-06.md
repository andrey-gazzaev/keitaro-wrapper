# CC-06. У кампании задан источник из API

Домен, группа и источник. Процесс — в [создателе кампаний](../../../campaign-creator.md).

## Шаги

Создать кампанию. До создания в API Keitaro есть хотя бы один источник.

## Ожидание

У кампании проставлен источник, и этот источник есть среди источников, которые отдаёт API Keitaro.
