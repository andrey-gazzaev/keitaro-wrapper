# CC-04. У кампании задан домен из API

Домен, группа и источник. Процесс — в [создателе кампаний](../../../campaign-creator.md).

## Шаги

Создать кампанию. До создания в API Keitaro есть хотя бы один домен.

## Ожидание

У кампании проставлен домен, и этот домен есть среди доменов, которые отдаёт API Keitaro.
