# CC-05. У кампании задана группа из API

Домен, группа и источник. Процесс — в [создателе кампаний](../../../campaign-creator.md).

## Шаги

Создать кампанию. До создания в API Keitaro есть хотя бы одна группа кампаний.

## Ожидание

У кампании проставлена группа, и эта группа есть среди групп, которые отдаёт API Keitaro.
