# AD-01. Поиск оффера по названию или id

Добавление оффера. Процесс и фикстура — в [обёртке над Keitaro](../../wrapper.md).

## Шаги

В выборе оффера ввести текст из названия или id существующего оффера и выбрать строку из списка.

## Ожидание

Интерфейс ходит в API обёртки. API забирает список офферов из Keitaro, оставляет совпадения по названию или id и возвращает не больше десяти. Пустой запрос и отсутствие совпадений дают пустой список. Оффер можно выбрать из списка.
